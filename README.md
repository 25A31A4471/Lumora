# LUMORA — Smart Expense Tracker

**Track smart. Save more. Live better.**

A premium, fully client-side expense tracker built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no backend, no build tools — just open it and go.

## ✨ Features

- 🔐 Demo login / signup (frontend-only, data stored in `localStorage`)
- 📊 Dashboard with live totals, monthly bar chart and category donut chart
- 💳 Full transaction CRUD with search, filters, sort, and CSV export
- 🎯 Monthly budgets with progress bars and threshold warnings (75% / 100%)
- 🐷 Savings goals with add/withdraw contributions and progress tracking
- 📈 Reports with income-vs-expense comparison across months
- 💬 **Lumi** — a friendly rule-based chatbot that answers questions about your money
- 🌙 Light and dark themes
- 📱 Fully responsive (desktop, tablet, mobile)

## 🚀 How to run

1. Open the folder in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey) if you don't have it.
3. Right-click `index.html` → **Open with Live Server**.

Or simply double-click `index.html` — no server required.

## 🧪 Demo account

Click **"Try the Demo Account"** on the welcome screen to load sample transactions, budgets, and goals.

## 🔒 Privacy note

LUMORA is a **frontend demo**. All data lives in your browser's `localStorage` and never leaves your device. Authentication is not production-grade — do not enter real sensitive information.

## 🛠 Tech stack

- HTML5
- CSS3 (custom properties, flexbox, grid, `conic-gradient` for the donut chart)
- Vanilla JavaScript (ES6+)
- No libraries. No CDNs. No build step.
